Списковий рендеринг через @for

Звичайного масиву достатньо для списку. Тут signal зберігає змінюваний список, а track item.id допомагає повторно використати елементи.

@for (item of testData(); track item.id; let index = $index) {

{{ index + 1 }}. {{ item.name }} (id: {{ item.id }})

} @empty {

Список порожній.

}

Порожній список через @empty

@for (item of emptyData(); track item.id) {

{{ item.name }}

} @empty {

Немає даних для показу.

}
