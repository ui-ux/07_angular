Classes via @ngClass

You can pass a string, an array, an object, or a conditional expression.

html result html
[ngClass]="'bg-tomato'" bg-tomato
[ngClass]="['bg-tomato', 'color-white']" bg-tomato
[ngClass]=" { 'bg-tomato': true, 'color-white': false }" bg-tomato
[ngClass]="true ? 'bg-tomato' : 'color-white'" bg-tomato
[ngClass]="highlighted ? ['bg-tomato', 'color-white'] : []" Enter the text to toggle the classes.
