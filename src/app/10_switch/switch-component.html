Кілька гілок через @switch

Кілька варіантів за числовим значенням

@switch (testCount) { @case (1) {

Значення 1: {{ testCount }}

} @case (5) {

Значення 5: {{ testCount }}

} @default {

Немає відповідного значення.

} }
