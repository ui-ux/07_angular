Change detection

Zoneless Angular

Zone.js traditionally patches asynchronous browser APIs and notifies Angular when to check for changes. A zoneless application instead relies on explicit change notifications, such as signal updates, bound events, and framework APIs.

Conceptual configuration

bootstrapApplication(AppComponent, {
  providers: [
    provideExperimentalZonelessChangeDetection(),
  ],
});
This page explains the concept only. The existing app uses AppModule and Zone.js, so zoneless change detection is not enabled globally.
