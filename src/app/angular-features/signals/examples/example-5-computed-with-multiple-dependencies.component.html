5. computed() with multiple dependencies

Computed signal може одночасно залежати від кількох signal-ів і оновлювати похідне значення.

price = signal(100);
quantity = signal(2);
discount = signal(0.1);
totalPrice = computed(() => price() * quantity() * (1 - discount()));

price: {{ price() }}

quantity: {{ quantity() }}

discount: {{ discount() }}

totalPrice: {{ totalPrice() }}
