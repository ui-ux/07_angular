4. computed() for derived state

Computed signal доступний лише для читання та перераховується, коли змінюються залежності. Він допомагає не дублювати похідні дані у змінному стані. 

firstName = signal('Demo');
lastName = signal('User');
fullName = computed(() => firstName() + ' ' + lastName());
initials = computed(() => firstName()[0] + lastName()[0]);

firstName: {{ firstName() }}

lastName: {{ lastName() }}

fullName: {{ fullName() }}

initials: {{ initials() }}
