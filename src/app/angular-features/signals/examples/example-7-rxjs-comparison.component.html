7. Signals and RxJS

Signals represent synchronous reactive state. RxJS Observables model streams over time and provide operators for asynchronous composition. 

count = signal(0);
count.update(value => value + 1);

count$ = interval(1000).pipe(scan(value => value + 1, 0));

Signal count: {{ signalCount() }}

Observable interval count: {{ observableCount$ | async }}
