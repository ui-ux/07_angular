1. Signal → Computed → Effect

Один signal задає похідне значення, а effect реагує на його зміни.

count = signal(0);
doubleCount = computed(() => count() * 2);

effect(() => {
  console.log(count(), doubleCount());
});

count: {{ count() }}

doubleCount: {{ doubleCount() }}

Effect output: logged when either signal changes (open the browser console).
