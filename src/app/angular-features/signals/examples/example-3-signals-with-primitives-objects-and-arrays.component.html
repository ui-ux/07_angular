3. Signals with primitives, objects, and arrays

A signal може зберігати примітив, об’єкт чи масив. Для об’єктів і масивів створюйте нове посилання, а не змінюйте попереднє на місці. 

count = signal(0);
name = signal('Demo');
isActive = signal(true);
user = signal({ name: 'Demo', age: 30 });
tags = signal(['angular', 'signals']);

count: {{ count() }}

name: {{ name() }}

isActive: {{ isActive() }}

user: {{ user().name }} / {{ user().age }}

tags: {{ tags().join(' | ') || 'empty' }}
