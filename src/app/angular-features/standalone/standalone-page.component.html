Angular components

Standalone components

Standalone components declare their own dependencies and can be imported directly by other standalone components or lazy-loaded routes. They do not need to be declared in an NgModule.

Standalone component

@Component({
  selector: 'app-example',
  standalone: true,
  imports: [RouterLink],
  template: '<a routerLink="/">Home</a>',
})
export class ExampleComponent {}

Lazy route

{
  path: 'example',
  loadComponent: () => import('./example.component')
    .then(module => module.ExampleComponent),
}
This learning project still starts through its existing AppModule. These standalone pages are loaded through the Router without changing the app's bootstrap strategy.
